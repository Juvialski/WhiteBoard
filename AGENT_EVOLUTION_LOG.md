# Agent Evolution Log

This file tracks the historical evolution of the AI Developer's patterns, rules, and architectural decisions. While the active rules are maintained in `AGENTS.md`, this log provides a chronological trail of the agent's adaptations over time to prevent `AGENTS.md` from becoming excessively large.

## Changelog

- **[2026-07-27]** Initial consolidation of multi-agent schemas into a unified playbook. Added explicit write-throttling and queue batching rules (`saveElementLocallyAndSync`, `simplifyPoints`) to strictly prevent Firebase `resource-exhausted` quota limits under heavy load.
- **[2026-07-28]** Codebase Reorganization Milestone: Successfully refactored monolithic `WhiteboardCanvas.tsx` into modular domain files under `src/components/canvas/` (`ElementWrapper.tsx`, `AiAssistantPanel.tsx`, `WhiteboardHeader.tsx`, `CanvasOverlays.tsx`, `canvasUtils.ts`). Verified 100% test pass rate across all 50 tests. Verified timer precision (`Date.now() - startedAt`) and non-blocking high-frequency WebSocket sync.
- **[2026-07-28]** Anti-Spam & Student Throttling Milestone: Implemented comprehensive anti-spam rate limiting and stroke filtering across all board element creation tools (`sticky`, `shape`, `text`, `math`, `stamp`, `audio`, image/clipboard paste). Capped student paste operations to max 10 elements per batch and native image pastes to max 5 images. Added stroke length path filtering (`< 2px`) in `handleMouseUp` to discard micro-scribble spam and accidental clicks. Integrated friendly toast warning messages when rate limits are exceeded. Verified clean compilation and test execution.
- **[2026-07-28]** Critical Quota Protection Fix: Addressed an infinite read/write chain reaction caused by overlapping Firestore background migrations. stray document deletion now executes as an atomic batch *before* blob shards are updated, wrapped inside an `isMigratingRef` guard. This completely severs recursive `onSnapshot` re-fires.
- **[2026-07-29]** Strict Student Permissions & UI Refinement: Completely gated image resizing, connector handles, stroke/shape selection, and canvas panning/zooming (touch, wheel, mouse drag) behind `canWrite`. Removed the settings gear icon from the main toolbar and streamlined header undo/redo button vertical heights.
- **[2026-07-29]** Student Timer Lock & Auto-Show Sync: Gated timer controls (start, pause, reset, mode switch, time editing, presets, +1m/-1m adjustments) behind `canWrite`/`isReadOnly` state. Transmitted real-time timer visibility (`isOpen`) across WebSocket `timer_sync` messages so that when the teacher opens or closes the Sprint Timer widget, all student devices automatically show or hide the synchronized timer widget in real time with read-only controls.
- **[2026-07-29]** Student Laser Pointer Restriction: Restricted the Laser Pointer tool under locked student access (`!canWrite`). Added `canWriteRef` checks in `handleMouseMove` to block emitting or storing laser points when write permissions are disabled, auto-cleared active local laser points, and automatically reset student active tools back to `select` when write permissions are toggled off by the teacher.
- **[2026-07-29]** Resilient AI Key & Model Fallback Engine: Updated `safeGenerateContent` in `/server.ts` and `AiAssistantPanel.tsx` model selector options to support all exact Gemini API model strings (`gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.1-pro`, `gemini-3.0-flash`, `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-2.0-flash-lite`, `gemini-flash-latest`). Provided clear action guidance if the user's personal key is invalid or expired.
- **[2026-07-30]** Sprint Timer Accuracy & Ticking Fix: Stabilized `WorkspaceTimer`'s sync callback with `useRef` and `useCallback` in `WhiteboardCanvas.tsx` to eliminate interval teardowns caused by canvas re-renders during active mouse/drawing interactions. Refactored timer clock logic to millisecond precision (`Date.now() - startedAt`) to prevent fractional second drift on pause/resume, and improved input field editing for minute/second inputs when setting custom countdowns.
- **[2026-07-30]** Sprint Timer Freeze Elimination & Timestamp Self-Healing: Resolved an issue where `startedAt` timestamps could resolve to `null` or `undefined` when `isRunning` was `true` (e.g. during remote state updates or component re-renders), causing `getCurrentDisplaySeconds()` to fall back to `remainingSeconds` and freeze the displayed countdown. Enforced automatic numeric timestamp parsing (`Number(raw)`) and timestamp self-healing (`Date.now()`) across `syncedState` effects, `getCurrentDisplaySeconds()`, `setInterval` tick loops, and `handleStartPause` handlers. Updated `WhiteboardCanvas.test.tsx` to test Sprint Timer modal rendering. Verified 100% test pass rate across all 50 unit tests.
- **[2026-07-30]** Firestore Write Quota Optimization: Identified and eliminated the root causes of excessive Firestore writes in a single session. Removed `dailyReads` `setDoc` write calls from `onSnapshot` listeners and removed `dailyWrites` / `teacherDailyWrites` batch updates from `flushPendingChanges` in `WhiteboardCanvas.tsx` to eliminate telemetry self-write feedback loops. Optimized presence tracking in `App.tsx` by detaching `boardId`/`boardName` effect re-mount churn and enforcing a strict 60-second write throttle. Verified clean compilation and 100% test pass rate.
- **[2026-07-30]** Permanent Sandbox Firebase Ban Milestone: Created `src/utils/firebaseSandboxGuard.ts` to detect the AI Studio Sandbox environment (`ais-dev-*`, `localhost`, `127.0.0.1`). Permanently banned and short-circuited all Firestore reads/writes (`getDocs`, `setDoc`, `addDoc`, `deleteDoc`, `onSnapshot`) in Sandbox mode, routing all board elements and board metadata through ultra-fast `localStorage` persistence. Ensured full zero-quota consumption when working inside the AI Studio Sandbox, while preserving real Firebase syncing when deployed to the Shared/Production environment (`ais-pre-*`). Verified clean linter execution and build compilation.
- **[2026-07-31]** Dynamic Stamp Shape Modification & AI Stamp Suite Milestone: Expanded default feedback stamp shapes to 11 custom geometry options (`rounded-rect`, `circle`, `star`, `badge`, `diamond`, `banner`, `hexagon`, `ribbon`, `heart`, `shield`, `crest`). Added live interactive shape changing for existing stamps placed on the canvas via direct on-canvas floating context controls and the left Properties Panel. Implemented server-side `/api/ai/stamp` endpoint utilizing `@google/genai` with custom key validation and redirect link for Google AI Studio API key generation. Verified clean linter execution and build compilation.
